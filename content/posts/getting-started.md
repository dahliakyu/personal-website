## Prerequisites

- Node.js 18 or higher
- A package manager (npm, pnpm, or yarn)

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your/repo
cd repo
npm install
```

## Running Locally

```bash
npm run dev
```

The site will be available at `http://localhost:3000`.
