## Why Documentation Matters

Good documentation is often the difference between a project that gets adopted and one that gets ignored.

## The Golden Rules

1. **Write for your audience** — assume they are smart but busy.
2. **Lead with examples** — show before you explain.
3. **Keep it close to the code** — docs that live far from the source rot quickly.

## Structure

A solid doc page has four parts:

- **What it is** — one sentence.
- **Why use it** — the problem it solves.
- **How to use it** — a minimal working example.
- **Reference** — exhaustive details for power users.
